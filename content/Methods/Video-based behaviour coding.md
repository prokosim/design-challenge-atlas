## What it is

Systematic annotation of recorded sessions: each relevant event (action, error, hesitation, recovery) is coded with a timestamp using a predefined coding scheme.

## How it works

1. Define a coding scheme (e.g. correct action, use error, close call, recovery).
2. Code the video — live or afterwards — ideally with two coders.
3. Check inter-rater reliability.
4. Derive frequencies, durations and sequences: [[Use error rate]], [[Error recovery time]], [[Time to first correct action]].

## Strengths

- Turns observation into quantitative, auditable data.

## Limitations

- Very labour-intensive (often several hours of coding per hour of video).
- Depends on coder skill and on a good coding scheme — see [[Automated use-error detection and classification]].
