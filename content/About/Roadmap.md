## v0.1 — MVP (now)

- 8 entity types, one ontology file, Obsidian authoring, Quartz website.
- Pilot domain: human factors / usability / physical ergonomics, two case studies.
- Trust model (status, evidence, origin, last verified) and computed overviews.
- GitHub contribution flow: issue forms → review → auto-generated pull request → checks → website.

**Success test:** a visitor can go from *"I have a problem"* → *"what should I measure?"* → *"how?"* → *"with which tool?"* → *"where is there no good tool?"*

## Next

- Review and verify the pilot content; invite first external contributors.
- Add domains: logistics (from *Rethinking.Logistics*), accessibility, safety, manufacturing, sustainability.
- Decide licensing for content and code.
- Consider more structure where it proves necessary (e.g. separate *Requirement* notes under standards, separate *Design question* notes).

## Later

- A richer finder (filters by domain, quantity, cost, setting).
- An AI assistant that answers **only from the Atlas and its sources** — structured knowledge first, AI interface second.
- Export of the gap register as an "opportunity map" for research and product development.
